# 📂 Automação de PDFs - DACTE

Script em Python para automatizar a organização de arquivos PDF em empresas.  
O programa lista, renomeia e move automaticamente documentos PDF para uma pasta organizada.

## Funcionalidades

- 📄 Listar arquivos PDF de uma pasta
- ✏️ Renomear arquivos automaticamente
- 📂 Mover os arquivos para uma pasta organizada
- ⚡ Automatizar tarefas repetitivas

## 🛠 Tecnologias utilizadas

- Python
- Biblioteca `os`
- Biblioteca `shutil`
